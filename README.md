# Национальная политика. Образование СССР (1917–1930-е гг.)

Учебный проект по истории: презентация, текст доклада и интерактивный квиз в едином стиле **советский конструктивизм / архивная эстетика 1920-х**.

## 🎨 Цветовая палитра
- **Кремово-пергаментный фон** — `#F4EFE6`
- **Плакатный красный** — `#A62626`
- **Графитовый чёрный** — `#1C1C1C`
- **Золотистая охра** — `#C8963E`

## 📦 Состав проекта

```
repo_ussr_national_policy/
├── National_Policy_USSR_Formation.pptx      # Презентация (12 слайдов)
├── Доклад_Национальная_политика_Образование_СССР.docx  # Текст выступления
└── index.html                               # Интерактивный квиз для GitHub Pages
```

### 1. Презентация (`National_Policy_USSR_Formation.pptx`)
**12 слайдов** с конструктивистской вёрсткой:
1. Титульный: тема, период, стиль
2. Предпосылки объединения советских республик
3. Споры о принципах: план «автономизации» Сталина vs план федерации Ленина (сравнительная таблица)
4. I Всесоюзный съезд Советов (30.12.1922) — 4 республики-учредителя
5. Конституция СССР 1924 г. — структура власти, значение
6. Коренизация: меры и результаты к 1930 г.
7. Создание письменности для бесписьменных народов и ликбез (таблица с алфавитами)
8. Противоречия коренизации: внутренние проблемы и реакция центра
9. Свертывание курса в 1930-е: хронология 1930–1938 гг.
10. Итоги: достижения и цена (две колонки)
11. Ключевые даты и цифры — шпаргалка (таблица)
12. Заключение: уроки истории

### 2. Текст доклада (`Доклад_Национальная_политика_Образование_СССР.docx`)
- Связный речевой текст для чтения с трибуны
- Полностью дублирует логику и факты презентации
- Метки переключения слайдов: `[СЛАЙД 1]` … `[СЛАЙД 12]`
- Оформлен в Times New Roman, 14 пт, полуторный интервал, красные заголовки

### 3. Интерактивный квиз (`index.html`)
**Готовый к загрузке на GitHub Pages** (один файл, без внешних зависимостей кроме Google Fonts):
- Стартовый экран с названием и кнопкой «Начать проверку знаний»
- 10 вопросов строго по материалу презентации
- Прогресс-бар с анимированной полосой
- Мгновенная проверка: подсветка правильного/неправильного + историческая справка
- Клавиатурное управление (A/B/C/D, Enter)
- Финальный экран: счёт, процент, **историческое звание** (6 рангов от «Слушатель рабфака» до «Наркома по делам национальностей»)
- Кнопка «Пройти заново»
- Полная адаптивность (мобильные / ПК)
- Вся графика — CSS и inline SVG, никаких внешних картинок

## 🚀 Развёртывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите содержимое папки `repo_ussr_national_policy/` в корень репозитория
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo-name>/`
